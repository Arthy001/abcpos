# Project Rules

## 1. Code Editing Restrictions
- **DO NOT edit code directly** without presenting a plan first.
- Always propose a plan before making any code changes.
- Wait for explicit approval before implementing.

## 2. Git Restrictions
- **DO NOT commit** changes yourself.
- **DO NOT push** to GitHub yourself.
- Leave version control operations to the user.

## 3. Communication
- Be concise and direct.
- Present plans clearly before implementation.
- Do not engage in back-and-forth conversations.
